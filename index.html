04 / How I work

Four steps, from a WhatsApp message to a live page

Small over clever. I would rather ship a page that opens in a second than one that only looks good in a screenshot.

  1. 01

    Ask

    You send one message on WhatsApp. I ask what it must do, and for anything you already have.

  2. 02

    Plan

    I write a short list of what will be built and what will not, then send you the layout as plain text.

  3. 03

    Build

    Mobile first, one part at a time. The phone sizes get settled before the desktop ones do.

  4. 04

    Hand over

    You get every file, where it lives, and how to change the words yourself later.
